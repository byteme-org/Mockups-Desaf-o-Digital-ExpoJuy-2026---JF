# ExpoJuy 2026 🏔️

Propuesta de sitio web oficial para **ExpoJuy 2026**, presentada en el marco del **Desafío Digital ExpoJuy 2026** (Ministerio de Desarrollo Económico y Producción de Jujuy, Dirección Provincial de Servicios Basados en el Conocimiento, Cámara de Comercio Exterior de Jujuy y ClusteAr).

Esta es la etapa de **propuesta conceptual y visual**: no es el sitio final, sino un mockup navegable que muestra cómo podría verse y organizarse la web de ExpoJuy 2026.
